# R14 · 数据接入与运行准备

四轮补充开发的第4轮。基础几何仍为 R10 / 447 构件。本轮提供接入框架；尚无真实 SCADA/CMS 数据源、厂家阈值及生产部署验收。

## 使用

进入“设备监测”，右侧首先显示“数据接入”。支持导入 JSON 快照和同源 HTTP 轮询。快照会随真实时间过期，不冒充实时连接。接入数据与教学仿真分开，不控制风机、停机或储能。浏览器保留最近500条告警事件，可按时间筛选、确认、导出；趋势每点最多300个有效样本。确认不解除告警；此历史不作为可靠审计存储。

默认没有任何健康阈值。规则模板为 `data/telemetry-rules-template.json`，重新加载页面需重新导入规则。规则导入清空当前测点状态并保留历史，等待新样本。warning / alarm 为上限值，holdMs 是持续采样时间，hysteresis 是回差；必须经过现场确认后配置。缺失、坏质量、不确定、单位错误、乱序、未来时间、超时数据均不产生正常结论，亦不恢复既有告警。重复样本不累加持续时间。

## 数据契约

```json
{
  "schemaVersion": 1,
  "sourceId": "由现场填写",
  "turbineId": "由现场填写",
  "points": [
    {"key": "main_bearing_temperature", "value": 52.1,
     "unit": "degC", "quality": "good", "timestamp": "2026-10-17T00:00:00Z"}
  ]
}
```

上述为格式示例，并非实际观测。每次返回完整快照，未返回的测点标记缺失。支持 UTC 毫秒或带时区 ISO 时间；quality 为 good / bad / uncertain。14个 key、单位及构件绑定见 `viewer/telemetry-points.mjs`，现场标签见 `data/测点映射模板.csv`（待填写）。值必须为有限数字，不做隐式单位转换。数据源与机组变化需要重新连接。

## 本地预览与适配

```bash
python3 start_viewer.py --bind 127.0.0.1 --port 8788
./status.sh http://127.0.0.1:8788
# 采集器写入公开目录之外的快照，可选：
python3 start_viewer.py --bind 127.0.0.1 --port 8788 --telemetry-file /path/outside-delivery/snapshot.json
```

入口 `/viewer/`；`/api/health` 返回 R14 版本、服务可用状态及是否配置文件；`/api/telemetry` 未配置或读取失败返回503。health 可用不表示测点新鲜。采集器应原子替换快照文件，限制1MiB。离线 HTML 只支持文件导入；仅托管 dist 的静态站点需要另外配置同源接口。

这是本地预览服务，无认证、TLS、后台历史库或多用户权限。生产交付还需确认采集协议/网络、机组点表、单位、时钟同步、阈值依据、凭据隔离、访问控制和持久化策略，在目标环境完成断网、恢复、设备切换及读写权限验收。此处未部署生产服务。

## 性能

“低画质”将渲染像素比限制为1；后台页停止绘制和 HTTP 轮询，数据有效期继续使用真实时间。教学仿真时间不用于接入数据判据。

## 验证

- Node 8组测试：健康、回放、场景、仿真、储能能量、数据质量、转矩与教学。
- 浏览器脚本：`tests/browser-r14-check.js`，覆盖导入、无默认判据、告警确认、坏质量、构件定位和低画质。
- HTTP 集成：`python3 tests/test_server.py`；当前环境拒绝创建 socket，尚未完成真实 HTTP 验收。
- `SHA256SUMS` 校验交付文件；版本清单 `data/viewer-release.json`。
