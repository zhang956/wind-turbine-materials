# R13 第三轮：储能与风机功率联动

进入“运行演示”，滚动到“配套储能”，开始仿真后选择储能模式。

## 模式与参数

- 待机：电池不充放电，风机功率送网。
- 手动充电：按请求功率充电，受风机功率、额定功率和SOC上限约束。不从电网购电。
- 手动放电：按请求功率放电，受额定功率和SOC下限约束。
- 自动平滑：风机功率高于送网目标时充电、低于目标时放电；受限制时不能保证达到目标。

默认教学配置：容量2 MWh、功率上限0.5 MW、SOC范围10%–90%、初始50%、单向效率95%，手动请求0.3 MW，自动目标1 MW。可在参数折叠区修改；“应用参数并重置储能”才提交。容量允许0.01–100 MWh，效率1%–100%；非法配置不改变已应用配置或电量。

初始与边界SOC必须满足下限≤初始≤上限。应用参数会把储能恢复初始SOC、待机并清空累计充放电和损耗；不会重置风机或清空历史快照。

## 功率与能量

所有充放电功率读数是交流侧MW，电量是MWh。送网功率 = 风机功率 + 放电功率 − 充电功率。

每步电池电量变化 = (充电功率×效率 − 放电功率÷效率)×仿真秒÷3600。转换损耗已包含在AC/DC转换中，不能再次从送网功率扣除。

显示上一仿真步的平均功率；达到SOC边界的最后一步可能有少量充放电，下一步归零。箭头只在实际功率大于阈值时显示方向。SOC、电量、累计充放电和累计损耗可同时查看。

## 时钟与回放

- 暂停冻结积分和箭头运动；慢放同步缩短能量积分时间。
- 切视图隐藏储能也继续计算，保持全局能量一致。
- 仿真复位按已应用配置恢复初始SOC、待机并清空累计值；配置本身保留。
- 快照保存储能配置、模式、SOC、电量、功率及累计值。回放显示历史读数与箭头方向，不改写当前电量；退出恢复当前值且风机仍保持暂停。
- 本轮不新增回放文件导入导出；历史仅在当前页面会话内保留。

全部为教学配置，不是V90标配或厂家BMS/EMS参数。不模拟并网保护、寿命衰减、温控、辅助耗电和真实调度；风机故障停机后，储能仍可按所选模式放电，不代表真实并网许可。
