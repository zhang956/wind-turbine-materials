# R09 Health Monitoring Implementation Plan
Goal: 按已批准的五组方案交付可定位的健康参数与趋势。
Architecture: health-data.mjs定义分组、参数、演示采样与判据；health.js负责DOM、屏幕标记和趋势。simulation-panel.js提供elapsed/epoch时钟用于暂停慢放复位。
Tech Stack: 原生JS/Three.js/SVG，无依赖增加。
- [x] tests/health.test.mjs先验证未接入、采样、异常隔离、阈值原因、暂停和复位。
- [x] viewer/health-data.mjs实现纯数据会话，输入state/wind/clock，输出五组指标与最多60点历史。
- [x] viewer/health.js绑定五个AssetId，使用世界包络中心投影到屏幕；按钮定位，趋势按选定指标单位绘制。
- [x] viewer.js/index.html接入；simulation-panel.js提供统一时钟；回归原测试并打包、同步dist、更新说明和哈希。
