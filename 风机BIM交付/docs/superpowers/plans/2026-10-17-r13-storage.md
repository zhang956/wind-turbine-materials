# R13 第三轮：风储功率与能量联动

沿用已批准第三轮范围和原生模块，不发布、不修改基础几何。
- [x] 纯模型：MWh/MW/仿真秒单位；容量、功率、SOC、效率、风机充电来源约束；待机/手动充放/目标送网自动模式。
- [x] UI：配置提交重置储能；实时SOC、能量、交流功率、损耗和累计能量；箭头按实际功率显示。
- [x] 时钟：随风机仿真暂停/慢放；隐藏储能也积分；仿真复位恢复配置初始SOC、待机并清零累计量。
- [x] 回放：保存完整储能快照；回看历史SOC和功率，退出恢复实时状态，不二次积分。
- [x] 验证：能量守恒与上下限测试、实际DOM与浏览器联动检查、既有回归；R13离线/dist/版本/校验和同步。

默认教学参数：容量2MWh、额定0.5MW、SOC10%–90%、初始50%、单向效率95%、手动0.3MW、送网目标1MW。
交流功率平衡：送网=风机+储能放电AC−储能充电AC。电池能量变化=充电AC×效率−放电AC÷效率；损耗已包含在AC/DC转换中，不能再次从交流送网中扣除。无电网购电，不模拟并网保护或厂家调度。
