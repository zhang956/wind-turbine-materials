# R11 故障教学联动

浏览入口：`viewer/index.html`（通过HTTP服务）或 `打开三维模型.html`（离线）。本地站点 `../风机BIM网页站点/dist/index.html` 与离线入口同步；未发布线上站点。

## 操作

1. 进入“故障教学”，点击顶部“开始 / 继续”。
2. 右侧勾选“启用演示数据”，选择主轴承温升或齿轮箱振动异常。
3. 观察红色构件框、监测标记、顺桨减速和事件时间线。暂停会冻结运动及采样；场景变化后会提示等待下一采样。
4. 点击“清除异常”；停机仍锁存。点击“确认告警”，等待转速低于0.05 rpm且桨距至少85°。
5. 点击“手动解除故障锁存”；之后既有风况策略仍决定是否启动。解除故障不会强制恢复被手动暂停的仿真。
6. 可导出最多200条教学事件JSON。时间采用仿真秒，受暂停与慢放影响；新事件挤出最旧记录。复位仿真开始新会话，清除旧事件和故障。

四种操作模式仅调整控件分组，不重置仿真。顶部状态条一直显示运行状态，并提供暂停/继续。
关闭演示数据仅清除异常源、清空监测值，不解除已锁存停机。

## 边界

全部为本地教学逻辑，未接SCADA/CMS或实际风机控制器。停机门限与恢复条件不是厂家保护参数。基础几何仍为R10，447个构件；网页储能扩展、测点、动画和事件不包含在基础GLB/IFC下载中。版本及SHA256见 `data/viewer-release.json`。

## 验证记录

- Node：故障锁存、清除/确认/恢复门控、立即停止偏航、暂停、复位、事件容量及待采样状态通过。
- 既有仿真、转矩、健康、运动和储能回归通过，包括真实447构件GLB上的运动验证。
- 本地esbuild打包通过；离线HTML与dist入口字节一致；版本清单哈希和447个唯一构件编号检查通过。
- Chromium真实浏览器操作脚本 `tests/browser-training-check.js` 已通过模式切换、停机/恢复、监测联动、暂停、关闭数据和复位检查。
- 三维显示检查：当前无头Chromium的整页截图遗漏WebGL画面，但同步 `renderer.render()` 后立即 `canvas.toDataURL()` 导出可见风机、网格及储能；画布位置、尺寸正常。证据见 `tests/r11-diagnostic.png`。因此功能与画布绘制通过，整页截图合成存在环境限制，不据此声称所有浏览器的视觉验收完成。
- HTTP服务的本机/局域网可达性未在本轮重新验收。

复现浏览器检查：先运行 `python3 tests/prepare_browser_check.py`，再用Chromium打开生成的 `tests/browser-check.generated.html`。该测试页会自动执行场景，并在底部显示PASS/FAIL；不是正式交付入口。
