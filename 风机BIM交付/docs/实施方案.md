# V90-2.0 MW 公开资料重建 BIM 实施方案

执行授权：用户于 2026-10-16 确认 BIM 方式并要求开始执行。

## 目标与边界
交付可编辑 Blender 模型、IFC4 构件模型、GLB 展示模型、部件清单、静态结构视图和资料精度说明。它是公开资料重建模型，不是原厂设计文件、竣工 BIM 或制造图。无 Revit 运行环境，不生成或冒充 RVT/RFA。

以官网 2017 年制作、2018 年修改的中文 2MWfinal.pdf 为基准。第 10 页提供 V90 参数；第 8–9 页为平台级内部图，不能证明具体批次完全一致。坐标单位米，Z 向上，X 为传动轴方向；地面 z=0，选取轮毂高度 80 m。无地理坐标。

## 实施任务
- [x] 1. 建立来源索引、尺寸参数和证据等级；冻结当前重建配置。
- [x] 2. 参数化建模整机、传动链、变桨、偏航、电气、辅助系统；每个对象有稳定 ID、名称、系统、证据、尺寸状态。
- [x] 3. 从同一模型导出 IFC4、GLB、JSON、CSV，维持编号映射。IFC 使用项目/场地/整机/系统层级，几何单位米。
- [x] 4. 制作整机、机舱开放、正侧视和爆炸视图，整理说明与文件索引。
- [x] 5. 检查 IFC 可读取性、GUID 唯一、构件与清单一致、GLB 文件结构、几何数值及渲染结果。

## 文件与接口
- `src/build_model.py`：Blender 参数建模、渲染、GLB 导出和几何交换。
- `src/export_ifc.py`：读取 `data/mesh_exchange.json`，生成 `models/V90_reconstruction.ifc`。
- `data/mesh_exchange.json`：`{project: {...}, components: [{id,name,system,ifc_class,evidence,source,notes,vertices,faces,color}]}`；vertices 为米制世界坐标，faces 为 0 起始三角形索引，color 为 RGBA。
- `data/components.json/csv`：构件编号、系统、尺寸包络、IFC GUID、证据及来源；不包含大体积网格。
- `models/V90_reconstruction.blend`、`V90_reconstruction.glb`：同源模型；对象 extras 保留属性。
- `preview/`：静态结构视图；`docs/`：来源、边界、操作说明、验证记录。

## 真实性约束
A=官方文字确认的参数或系统类型；B=平台图参考布局；C=为展示建立的估算/示意几何。构件形状不得仅因系统存在被确认就宣称 A 级几何。
齿轮内部不虚构精确齿数/传动比；轴承滚动体、螺栓、叶片翼型/扭角、塔筒分段和基础均为示意。基础单独标记场址未定；所有测点是待映射模板，不伪造实时数据。
不提交 Git、不修改原有视频及资料文件。
