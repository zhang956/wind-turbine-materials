# R12 第二轮：场景、启停、回放与教学引导

本轮基于R11，基础几何仍为R10的447个构件。

## 新增操作

- 右侧教学异常增加“叶片1变桨迟滞”和“偏航驱动异常”。迟滞使叶片1以1°/s响应，另两片以8°/s响应；三维角度和监测数值一致。偏航异常冻结朝向并锁存教学停机。以上均为教学假设，不是厂家参数或真实故障诊断。
- “正常停机”顺桨减速并保持；“允许启动”仅解除正常停机请求。它不能解除故障锁存，也不会解除手动暂停。
- “暂停”冻结演示时间，与正常停机不同；“复位”恢复初始状态并清空事件和回放。
- 故障恢复要求：异常源清除、告警确认、转速低于0.05rpm、三片桨距均至少85°，最后手动解除锁存。
- 故障教学面板按当前状态显示下一步操作；所有场景沿用观察、清除、确认、停稳、恢复的过程。

## 回放

运行后在“过程回放”进入，或点击事件旁的“回看”。记录每仿真秒的姿态、风况和教学故障状态，事件变化立即补录。同一仿真时刻的清除和确认保留各自快照。

保留最近600仿真秒，最多1200帧；旧记录会被淘汰。超出保留范围的事件明确提示无法回放，不跳到错误时刻。暂停或慢放沿用仿真时钟。记录仅存于当前页面，刷新或复位即清空。

回放支持播放、暂停和拖动时间条，按记录帧呈现，不进行重新推演或插值。回放时禁用编辑、隐藏实时健康面板，左侧显示该帧的风速、转速、三片桨距、朝向、功率和故障状态；仍可拖动三维视角。退出还原实时姿态、保持暂停；未启动时进入回放也保留原分解姿态。

事件JSON继续只导出事件记录，未导出完整回放帧。

## 验证

- Node：新增场景、全部叶片恢复门控、正常停机/启动、快照隔离/限额/复位、历史风向计算通过；已有仿真/健康/转矩/储能测试通过。
- 实际447构件GLB：叶片1独立变桨，另外两片同步变桨；原有主轴倾角、传动、偏航、复位回归通过。
- Chromium检查脚本：`tests/browser-r12-check.js`；准备测试页：`python3 tests/prepare_browser_check.py --r12`。测试页为临时验证入口，正式入口仍为 `打开三维模型.html` 和 `viewer/index.html`。
- 本机无头截图会遗漏WebGL图层，测试页使用同帧画布导出叠加显示，不改变正式产品页面；该截图不代表全浏览器兼容性验收。

本轮不接入SCADA/CMS，不修改基础模型，不发布线上站点，也未重新验证8788服务的本机/局域网可达性。
