# R15 故障教学完善

进入“故障教学”，左侧选择四类场景之一：主轴承温升、齿轮箱振动、叶片1变桨迟滞、偏航驱动异常。

1. 阅读现象、观察重点、原理边界及分析提示。选择场景仅预览，不注入。
2. 开始仿真，再点击“注入所选故障”。自动启用教学数据，保留当前风况；暂停时可注入，动作待继续后推进。
3. 观察三维红框、顺桨减速和右侧演示指标。偏航场景建议预先设置有风向偏差的工况。
4. 清除异常、确认告警，查看五项恢复检查：异常已清除、告警已确认、风轮停稳、叶片1顺桨、叶片2/3顺桨。
5. 全部满足后手动解除锁存。页面记录本会话完成次数，保留最近场景说明，可回看事件。

新注入入口在故障锁存期间禁用，避免误开下一练习。原右侧场景入口仍可使用，注入时会同步左侧场景说明。选择另一场景预览不改变当前故障，当前故障以状态栏为准。

恢复门槛采用现有教学规则：0 ≤ 转速 < 0.05 rpm，三片桨距均 ≥ 85°。叶片2与3使用当前仿真共有桨距；叶片1可独立迟滞。无效数值不能解除锁存。完成次数表示成功手动解除的次数，不是考核评分，也不表示风机已恢复发电。

进入历史回放会隐藏实时教学卡片并锁定操作，避免将当前检查结果误读为历史状态。退出后保留原状态并暂停。仿真复位清空会话完成次数和事件；导出JSON包含完成次数和教学事件。

内容与阈值均用于教学演示，不是厂家保护定值、根因诊断或现场作业指导。接入数据和教学数据继续分开。基础447个构件与R10几何保持不变。
